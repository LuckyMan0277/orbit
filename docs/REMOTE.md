# Orbit 원격 연결

휴대폰·태블릿·다른 PC의 브라우저에서 Orbit의 실행 중인 터미널을 조작하고, 저장된 Codex·Claude 대화를 이어 열거나 새 세션을 시작합니다. 명령은 원래 PC에서 실행됩니다. 브라우저를 닫아도 PC 세션은 유지되지만, PC와 Orbit은 켜져 있어야 합니다. PC 절전·종료 상태에서는 사용할 수 없습니다.

## 처음 연결

1. PC의 Orbit에서 **외부 연결 → 외부 주소 준비**를 누릅니다. 기본 제공자는 Tailscale Funnel이며, 별도로 도메인을 구매하지 않습니다.
2. Tailscale 로그인이나 첫 Funnel 승인이 필요한 경우에만 브라우저가 열립니다. 승인을 마치면 Orbit으로 자동으로 돌아옵니다.
3. **계정** 항목에서 이메일·비밀번호로 **계정 만들기**를 누르거나, 이미 계정이 있다면 **이 계정에 연결**을 눌러 이 PC를 그 계정에 연결합니다. 계정은 한 번에 PC 한 대에만 연결되며, 새 PC에서 연결하면 이전 PC의 연결은 그 계정에서 자동으로 대체됩니다.
4. 이제 휴대폰·노트북 등 어떤 기기에서든, 계정 서비스가 알려주는 로그인 주소로 접속해 같은 이메일·비밀번호로 로그인하면 이 PC의 작업 공간으로 곧장 연결됩니다. QR을 스캔하거나 링크를 옮길 필요가 없고, PC 쪽에서 매 기기를 따로 승인하지도 않습니다.

**다른 PC의 Orbit 앱에서 접속**: 계정을 이 PC에 연결하지 않은 PC에서 Orbit을 켜면 전체 화면 **Orbit 로그인**이 먼저 뜹니다. 계정 서비스 주소·이메일·비밀번호로 로그인하면 계정에 연결된 PC의 프로젝트가 궤도 홈으로 표시되고, 프로젝트를 누르면 그 PC의 터미널과 이전 대화가 앱 안의 별도 창으로 열립니다. **새로 고침**은 프로젝트 목록을 다시 가져오고 **로그아웃**은 로그인 화면으로 돌아갑니다. 접속하는 PC는 호스트로 등록되지 않고 Tailscale도 필요 없으며 비밀번호는 저장하지 않습니다. 파일 탐색·편집은 포함하지 않습니다. **자동 로그인**을 켜고 로그인하면 이메일·비밀번호를 이 PC에 Windows 사용자 키(DPAPI)로 암호화해 저장하고, 다음 실행부터 로그인 화면 없이 바로 궤도 홈이 열립니다(다른 사용자·다른 PC에서는 복호화할 수 없음). 비밀번호가 바뀌면 저장본을 지우고 다시 로그인을 요청하며, **로그아웃**하면 저장본도 삭제됩니다. **이 PC만 사용**으로 그 실행에서만 로그인 화면을 건너뛸 수 있고, **외부 연결 → 다른 PC에 접속**으로 다시 열 수 있습니다. 접속하는 PC에서 **계정 → 이 계정에 연결**을 누르면 그 PC가 새 호스트가 되어 기존 호스트의 연결이 대체되므로 누르지 마세요.

모바일 상단의 **연결 일시 중단**은 연결만 멈추며 이 브라우저의 로그인 상태를 지우지 않습니다. **다시 연결**을 누르거나 같은 주소를 다시 열면 다시 로그인하지 않고 작업 공간을 복원합니다. 로그인 상태를 지우려면 브라우저 저장소를 지우거나, PC의 **계정 → 연결 해제**로 이 PC를 계정에서 완전히 분리합니다. 연결 해제 후에는 새로 계정을 연결해야 어떤 기기에서도 다시 로그인할 수 있습니다.

## 연결 방식과 자원 사용

Orbit 서버는 `127.0.0.1:49821`에서만 수신합니다. Tailscale Funnel이 공개 HTTPS 연결을 PC의 작은 루프백 프록시를 거쳐 Orbit으로 전달합니다. 프록시는 HTTP Host를 로컬 서버 주소로 맞추며 연결 수와 요청 크기를 제한합니다. 휴대폰에는 Tailscale 앱이 필요하지 않습니다.

계정 연결은 별도의 작은 클라우드 서비스(`cloud/`)가 담당합니다. 이 서비스는 계정별로 비밀번호 해시와 PC의 현재 공개 주소·기기 토큰만 저장하며, 터미널 트래픽 자체는 중계하지 않습니다 — 로그인 후에는 브라우저가 PC의 공개 주소로 직접 연결합니다. Funnel/Cloudflare 주소가 바뀔 때마다 Orbit이 이 서비스에 최신 주소를 갱신 전송합니다.

Orbit은 사용자가 연결을 시작할 때 Funnel을 실행하고 마지막 연결 상태를 기억합니다. 연결을 켜 둔 채 Orbit을 종료했다면 다음 실행 때 연결을 복원합니다. **고급** 안의 **외부 접속 끄기**를 누르면 현재 원격 연결과 자동 복원이 해제되지만, 계정 연결과 이 PC의 터미널은 남습니다. 외부 접속 끄기·Orbit 종료 시 자신이 실행한 프로세스를 종료합니다. Tailscale의 Windows 서비스는 별도로 설치되어 계속 실행될 수 있습니다. 기존 Funnel 설정이 감지되면 Orbit이 임의로 덮어쓰지 않습니다.

일상적인 연결에는 공개 주소 응답 검사를 추가하지 않습니다. 문제가 있을 때 **고급 → 연결 상태 확인**으로 현재 공개 주소의 응답을 확인합니다. 주소 준비 직후에는 DNS 반영에 시간이 걸릴 수 있습니다.

고급 설정에서 계정 서비스 주소, 기존 공개 HTTPS 주소를 지정하거나 **임시 Cloudflare 연결 사용**으로 전환할 수 있습니다. 임시 주소는 재시작할 때 바뀔 수 있으므로 계속 사용하는 주소로는 기본 Tailscale 연결을 사용하세요. 제공자를 전환하면 Orbit이 실행한 이전 제공자는 중지됩니다.

**보안 트레이드오프**: 계정 로그인만으로 즉시 연결되고 PC 쪽 추가 승인이 없으므로, 계정 비밀번호가 유출되면 그 즉시 이 PC의 터미널을 조작당할 수 있습니다. 유사시 **계정 → 연결 해제**로 즉시 차단할 수 있습니다.

## 명령 입력과 재연결

- 세션 목록 위 **프로젝트** 선택은 PC 홈 화면의 최근 프로젝트 목록과 같습니다. 새 Codex·Claude·셸을 시작하면 선택한 프로젝트 폴더에서 열리고, 이전 대화 목록도 선택한 프로젝트로 좁혀집니다. PC의 현재 활성 폴더는 바꾸지 않으며, 파일 탐색·편집은 여전히 포함하지 않습니다.
- **이전 대화**에서 Codex·Claude 기록을 검색하고 선택하면 원래 작업 폴더에서 이어 엽니다. 이미 Orbit에 열린 같은 대화는 기존 터미널로 이동합니다. 목록은 PC와 같은 제한된 로컬 기록을 사용하며, 대화 기록 전체를 브라우저에 전송하지 않습니다.
- 이전 대화 옆 **×**는 선택한 대화의 로컬 저장 기록을 영구 삭제합니다. 제목을 확인하고 **영구 삭제**를 눌러야 실행됩니다. Orbit에서 이어 열어 실행 중인 대화는 먼저 터미널을 닫아야 합니다. 터미널 탭 닫기와 대화 기록 삭제는 별개입니다.
- 기본 **읽기 보기**는 긴 줄을 화면 너비에 맞춥니다. **원본 터미널**로 전환하면 PC와 같은 행·열 배치를 확인할 수 있습니다. 모바일은 PC 터미널 크기를 변경하지 않습니다.
- 세션 선택 옆의 **새 대화**에서 Codex·Claude 또는 셸을 시작합니다. 테마는 시스템·어둡게·밝게 중 선택할 수 있습니다.
- 세션별로 작성 중인 입력을 유지하고, 연결 복구 시 현재 터미널 화면과 이후 출력을 다시 가져옵니다.
- **보내기**는 작성한 내용 뒤에 Enter를 붙입니다. **입력만**은 마지막 Enter 없이 입력합니다.
- 입력창의 Enter는 줄바꿈이며 Ctrl/Cmd+Enter는 보내기입니다. 별도 Enter 버튼은 터미널의 선택·확인 화면에 사용합니다. Tab·Esc·방향키는 **다른 특수 키**를 엽니다.
- 네트워크 오류로 명령 전달 여부가 불분명하면 같은 명령을 자동 재전송하지 않습니다. 요청 번호와 서버 실행 식별자로 처리 기록을 확인합니다. PC가 다시 시작되거나 처리 기록을 확인할 수 없으면 내용을 보존하고 확인이 필요하다고 표시합니다.
- 로그인한 모든 브라우저는 같은 계정 토큰으로 실행 중인 세션에 입력합니다. 기기별 세부 권한은 이번 범위에서 보류했습니다. PC의 **계정 → 연결 해제**로 모든 로그인을 한 번에 무효화할 수 있습니다.

파일 탐색·편집과 PC 전원 제어는 원격 기능에 포함하지 않습니다. 출력이나 명령 내용은 서비스 워커의 오프라인 캐시에 저장하지 않습니다. 폴더 감시·프로젝트 색인·별도 모바일 실행 엔진은 추가하지 않습니다.

## 검증 상태

QR 페어링을 계정 로그인으로 교체한 뒤 다시 검증한 항목: 로컬 HTTP 경계를 통한 인증, 계정 토큰 발급·해지, 공개 Host 전달과 입력 중복 처리(`Orbit.exe --self-test`의 "Tailscale loopback transport preserves auth and POST routing"), 세션 API 전체(생성·스냅샷·롱폴·idempotent 입력)의 회귀 없음(`RemoteUiTest`), 클라우드 계정 서비스의 signup/login/link/push/unlink 및 로그인 페이지 라우트(`cloud/test`), 네이티브 전체 컴파일과 프런트엔드 번들 빌드. 모바일 검증은 로컬 서버와 결정적인 테스트 터미널을 사용합니다. 데스크톱 검증에서는 실제 CMD·PowerShell을 실행합니다.

**아직 이 세션에서 실행하지 않은 것**: 실제 WebView2 GUI를 띄우는 `--ui-test`(`AccountUiTest`·`MobileUiTest` 등)는 코드만 새 마크업(`.remote-account-section`, `#login` 등)에 맞춰 갱신했고 별도로 재실행해 확인하지는 못했습니다. 실제 Cloudflare Workers 배포(`wrangler deploy`)와, 그 배포된 주소로 PC에서 계정을 연결한 뒤 **다른 네트워크의 다른 기기**에서 로그인해 곧장 연결되는 전체 흐름도 아직 실기기로 확인하지 않았습니다. 배포 전에 이 두 가지를 반드시 실행해 확인하세요.

영구 삭제는 별도 시험용 기록으로 검증했습니다. Codex는 설치된 CLI의 실제 삭제 명령을 거쳐 원본·색인·입력 이력의 해당 항목이 사라지는 것을 확인했고, Claude는 원본과 관련 파일·색인·입력 이력을 확인했습니다. 다른 대화와 손상된 비대상 이력 행은 보존합니다. 사용자 대화를 시험 중 삭제하지 않습니다.
