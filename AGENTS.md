# Orbit project instructions

- Use GPT-6 Luna for code authoring and modification, prioritizing speed and token economy.
- Keep implementation work with one agent unless parallel work is necessary. Review, testing, and documentation may be handled separately.
- Keep Orbit lightweight: avoid background indexing, watchers, and unnecessary bundled runtimes.
- Keep the desktop UI minimal: use one titlebar, put optional actions in a compact menu or shortcuts, and avoid permanent toolbars unless a task needs one.
