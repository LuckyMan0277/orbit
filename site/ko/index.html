Windows용 에이전트 작업 공간

Claude Code, Codex, 셸을 한 창에서.

Orbit은 여러 프로젝트의 AI 코딩 에이전트를 나란히 실행하고, 지금 확인이 필요한 세션을 알려 주며, API 키를 대화에 노출하지 않고, 같은 터미널을 휴대폰에서 이어 쓰게 해 줍니다.

무료 오픈소스(MIT) · Windows 10 1809 이상 / Windows 11, x64 · 텔레메트리 없음

창이 아니라 세션 중심으로

Claude Code나 Codex를 여러 프로젝트에서 동시에 쓴다면, 터미널 창을 잔뜩 띄우는 대신 한곳에서 정리해서 관리할 수 있습니다.

프로젝트별로 묶인 세션

프로젝트와 에이전트를 함께 골라 세션을 시작합니다. 사이드바는 세션을 프로젝트별로 묶고, 작업 중 · 확인 필요 · 대기 · 끝남을 상태 점으로 보여 줍니다.

진짜 터미널

Claude Code, Codex CLI, PowerShell, CMD를 Windows ConPTY와 xterm.js로 실행합니다. 좌우·상하 분할(최대 8개)과 탭 순서 변경을 지원합니다.

저장된 대화 이어 열기

Claude·Codex의 로컬 대화 기록을 검색해 원래 작업 폴더에서 다시 엽니다.

API 키 보관

키를 PC에서 Windows DPAPI로 암호화해 두면 새로 여는 Claude·Codex 터미널에 환경변수로 들어가고, AI에게는 값이 보이지 않습니다. 프로젝트별 또는 전체용으로 저장하며, AI는 orbit-secret request로 필요한 키를 요청할 수 있습니다.

파일 탐색기와 편집기

주요 언어 구문 강조, UTF-8/UTF-16/CP949 인코딩과 LF/CRLF 유지, 외부 변경 충돌 감지, Markdown 미리보기를 제공합니다.

클릭 가능한 출력

터미널에 나온 파일 경로(file.js:12:3 포함), URL, 폴더를 클릭하면 각각 편집기, 브라우저, 탐색기로 열립니다.

가볍게 만들었습니다. 백그라운드 색인, 파일 감시, 상시 실행 런타임이 없습니다. C# / WinForms 호스트에 WebView2 화면 하나로 동작합니다.

휴대폰 · 태블릿

같은 터미널을 휴대폰에서 이어서

명령은 계속 내 PC에서 실행됩니다. Orbit은 이미 열려 있는 터미널에 다른 기기의 브라우저가 붙게 해 줄 뿐입니다.

이렇게 동작해요

  1. 외부 연결 켜기Orbit에서 이 PC를 호스트로 지정하면 Tailscale Funnel 또는 임시 Cloudflare 터널로 공개 HTTPS 주소가 만들어집니다.
  2. 어느 기기에서든 로그인브라우저에서 모바일 화면을 열고 Orbit 계정으로 로그인합니다. 앱 설치는 필요 없고, 홈 화면에 추가할 수 있습니다.
  3. 세션 고르기세션이 프로젝트별로 묶여 상태와 함께 보입니다. 입력을 보내고, 휴대폰에 맞춘 보기로 출력을 읽고, 새 Claude·Codex 세션도 시작할 수 있습니다.

알아 두세요

  • PC와 Orbit은 켜져 있어야 하며, 브라우저를 닫아도 세션은 종료되지 않습니다.
  • 터미널 트래픽은 브라우저에서 내 PC로 바로 연결됩니다. 작은 계정 서비스는 비밀번호 해시와 PC의 현재 공개 주소만 저장합니다.
  • 원격 접속은 기본으로 꺼져 있고, 계정 연결을 해제하면 즉시 차단됩니다.
  • 휴대폰·태블릿 전용 앱은 계획 중이며, 지금은 모바일 웹 화면으로 제공됩니다.

  • 텔레메트리는 없습니다. 네트워크는 업데이트 확인과 사용자가 켠 원격 접속에만 쓰입니다. 코드 서명 및 개인정보 정책을 참고하세요.

코드 서명 없음. 아직 코드 서명을 적용하지 않아 Windows SmartScreen이나 스마트 앱 컨트롤이 경고하거나 설치를 차단할 수 있습니다. 모든 릴리스는 공개 저장소의 태그된 커밋에서 GitHub Actions가 빌드합니다.
