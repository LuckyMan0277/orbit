Agent workspace for Windows

Claude Code, Codex and your shell — one window.

Orbit runs your AI coding agents side by side across several projects, shows which session needs you, keeps API keys out of the chat, and lets you pick the same terminals up from your phone.

Download for Windows View on GitHub

Free and open source (MIT) · Windows 10 1809+ / Windows 11, x64 · no telemetry

Built around sessions, not windows

If you run Claude Code or Codex on more than one project at a time, Orbit keeps them organised in a single place instead of a pile of terminal windows.

Sessions grouped by project

Start a session by picking a project and an agent. The sidebar groups sessions per project, with a status dot for working, needs attention, idle and finished.

Real terminals

Claude Code, Codex CLI, PowerShell and CMD run in Windows ConPTY with xterm.js. Split left/right or top/bottom, up to eight panes, and drag tabs to reorder.

Resume past conversations

Search your saved Claude and Codex conversations and reopen one in its original working folder.

API key vault

Keys are encrypted on your PC with Windows DPAPI and injected into new Claude and Codex terminals as environment variables. The AI never sees the value. Keys can be per project or global, and an agent can ask for one with orbit-secret request.

Files and editor

File explorer with syntax highlighting for common languages, UTF-8 / UTF-16 / CP949 and LF / CRLF preserved, external-change detection and Markdown preview.

Clickable output

File paths (including file.js:12:3), URLs and folders in terminal output open in the editor, browser or Explorer with a click.

Lightweight by design. No background indexing, no file watchers and no always-on runtime. A C# / WinForms host with a single WebView2 view.

Phone & tablet

Continue the same terminals from your phone

Your commands still run on your PC. Orbit just lets a browser on another device attach to the terminals you already have open.

How it works

  1. Turn on external accessIn Orbit, make this PC the host. It gets a public HTTPS address through Tailscale Funnel or a temporary Cloudflare tunnel.
  2. Sign in from any deviceOpen the mobile page in a browser and log in with your Orbit account. No app install needed; add it to the home screen if you like.
  3. Pick a sessionSessions are grouped by project with their status. Send input, read output in a phone-friendly view, or start a new Claude or Codex session.

Good to know

  • The PC and Orbit must stay on; closing the browser does not stop your sessions.
  • Terminal traffic goes straight from the browser to your PC. The small account service only stores a password hash and your PC's current public address.
  • Remote access is off by default and can be cut instantly by disconnecting the account.
  • A native phone and tablet app is on the roadmap; today it is a mobile web page.

Download

Get Orbit-Setup.exe from the latest release. It installs per user under %LocalAppData%\Programs\Orbit without administrator rights and can be removed from Windows Settings.

Latest release on GitHub

Requirements

  • Windows 10 1809+ or Windows 11, x64
  • .NET Framework 4.8 and the Microsoft Edge WebView2 Runtime
  • Claude Code and/or Codex CLI on your PATH to use those buttons (Claude Code, Codex CLI). Orbit does not install or sign in to them for you.

Updates and privacy

  • Orbit checks GitHub for a new version once when it starts, and updates only when you click the button.
  • No telemetry. Network use is limited to the update check and the remote access you turn on. See the code signing and privacy policy.

Unsigned releases. Code signing has not been set up yet, so Windows SmartScreen or Smart App Control may warn about or block the installer. Every release is built by GitHub Actions from a tagged commit of the public repository.
